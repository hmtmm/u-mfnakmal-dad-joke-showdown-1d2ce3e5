A program that writes one original dad joke — a dog, a newspaper, and a Wi-Fi router — to /output/entry.txt.

> Every morning I try to teach my dog to fetch the newspaper, but he keeps bringing me the Wi-Fi router. I guess he prefers his news wireless.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
